# 数字项目部封面生成

这个 skill 只做一件事：

**把一个标题，稳定渲染成固定模板封面。**

它不是开放式海报设计助手，也不是提示词生成器。

## 适用场景

当用户表达下面这些意思时使用：

- 给这篇文章做一张封面
- 按这个标题直接出图
- 做一张数字项目部风格的 AI 文章封面
- 给这个标题配一张 3:4 超清题图

如果用户要改品牌、改比例、改 slogan、换成别的视觉方向，不要用这个 skill，先说明这个 skill 是固定模板。

## 输入

必填输入只有一个：

- `文章标题`

可选输入：

- `输出路径`
  用户如果明确给了输出路径，就按它输出。
  如果没给，默认输出到 `digital-project-cover/output/cover.png`。

## 固定规则

第一版必须锁死这些元素：

- 输出比例固定 `3:4`
- 输出尺寸固定 `2160 × 2880`
- 输出格式固定 `PNG`
- 左上固定品牌头图
- 右上固定 `AI 文章` 渐变胶囊
- 左下固定 `数字项目部` 和 `用 AI 提升认知 · 用项目创造价值`
- 右下固定机器人主体

默认不支持：

- 修改品牌名
- 修改 slogan
- 修改主色
- 修改整体模板
- 切换多种版式

## 工作流

### 1. 先拿到标题

如果用户没给标题，先让用户补标题，不要直接运行脚本。

### 2. 运行本地渲染脚本

默认命令：

```powershell
python digital-project-cover/scripts/render_cover.py --title "<文章标题>" --output "digital-project-cover/output/cover.png"
```

如果用户给了自己的输出路径，就替换 `--output`。

### 3. 返回最终图片

默认只返回最终图片，不附提示词、不附中间排版说明。

## 标题处理原则

脚本会自动做下面这些事：

- 去掉首尾空白
- 自动分成 `3–5` 行
- 自动挑出 `1–2` 个重点词或重点行
- 为重点内容分配青绿到蓝紫的渐变样式
- 在标题过长时依次做分行、缩字号、缩小强调范围、微调字距

除非真的放不下，否则不要擅自改写标题原意。

## 资产准备

这个 skill 默认依赖这些资产：

- `assets/template-reference.png`
- `assets/robot-reference.png`
- `assets/robot-cube.png`
- `assets/brand-header.png`

如果这些资产还没准备好，可以手动运行一次：

```powershell
python digital-project-cover/scripts/render_cover.py --prepare-assets --template-reference "<整张模板图路径>" --robot-reference "<机器人图路径>"
```

只要资产已经存在，正常出图就不需要再传参考图路径。

## 失败处理

如果脚本报错，优先检查：

- 标题是不是空的
- 资产文件是不是缺失
- 输出路径目录是不是可写

如果导出的尺寸不是 `2160 × 2880`，把它视为失败，不要把错误尺寸的图交给用户。
